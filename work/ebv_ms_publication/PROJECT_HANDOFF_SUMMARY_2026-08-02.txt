SHORT VERSION
This project was rebuilt from a messy earlier EBV-MS molecular mimicry analysis into a reproducible computational immunology workflow. The final direction is not "we proved EBV causes MS" and not "we discovered BALF5-MBP mimicry." The strongest defensible claim is:

    We built an auditable HLA-DR15-focused computational workflow that uses experimentally established EBV-myelin pMHC molecular mimicry as a positive-control anchor, validates modeled pMHC inputs, ranks EBV-CNS candidate pairs by local pMHC structural and physicochemical similarity, and explicitly rejects uncalibrated TCR ternary predictions as evidence of receptor recognition.

The project is currently strong for science fair presentation and potentially publishable as a student-accessible computational/immunoinformatics paper, especially if reviewed by an adult scientific mentor. It is not yet a high-impact immunology mechanism paper because it lacks direct wet-lab TCR binding, activation, or patient validation.


PROJECT BACKGROUND
The biological theme is the connection between Epstein-Barr virus (EBV), HLA-DR15, and multiple sclerosis (MS). EBV infection and the HLA-DR15 haplotype are both major MS risk factors. The project focuses on whether EBV peptides and CNS/myelin peptides may produce similar peptide-MHC surfaces that could plausibly contribute to molecular mimicry.

The project originally included MHC-I, generic docking, and some simulated or weakly validated outputs. During the rebuild, the scope was narrowed primarily to HLA class II, especially HLA-DRB1*15:01 / DR15 biology, because MS risk and CD4 T-cell antigen presentation are the more relevant pathway for this project.

Important conceptual pivot:
- MHC-II / CD4 T-cell antigen presentation is now the primary pathway.
- MHC-I and antibody-related analyses are optional future branches, not central current evidence.
- The current paper should be framed as computational prioritization, not direct proof of pathogenic mimicry.


MAJOR CORRECTIONS MADE

   Correct version:
   - EBV BALF5(627-641): TGGVYHFVKKHVHES
   - Presented by HLA-DRB5*01:01, also called DR2a
   - Experimental pMHC structure: PDB 1H15
   - Human MBP(85-99): ENPVVHFFKNIVTPR
   - Presented by HLA-DRB1*15:01, also called DR2b
   - Experimental pMHC structure: PDB 1BX2
   - Both are part of the known Hy.2E11 cross-reactive system from prior literature.

   The correct interpretation is allele-pair switching across the DR15 haplotype, not same-allele DRB1*15:01 mimicry.

2. The HLA-A*02:02 / DRB*15:02 label issue was clarified.
   These labels were controls, not literal high-risk human alleles being claimed as central disease alleles. The main analysis moved away from those confusing legacy labels.

3. Legacy "human myelin" labels were corrected conceptually.
   Some sequences had been labeled as human myelin/CNS too loosely. The rebuild requires each peptide to retain provenance: organism, source antigen, accession, IEDB ID, HLA restriction, evidence type, and source URL where possible.

4. Simulated or hallucinated outputs were quarantined.
   The rebuilt publication workspace states that no simulated values, legacy labels, or unvalidated structural scores should be used as publication inputs.

5. TCR docking/ternary modeling was downgraded.
   The project tested whether ColabFold could model five-chain TCR-pMHC complexes using the known Ob.1A12 positive control. It failed the orientation benchmark, so the ternary results are not used as binding evidence.

RESULT 4: Ob.1A12 TERNARY TCR-pMHC TEST FAILED CALIBRATION
Files:

    src/evaluate_ob1a12_ternary_ensemble.py

Background:
The user modeled five-chain ternary complexes including:
- TCR alpha chain
- TCR beta chain
- HLA-DRA
- HLA-DRB
- peptide

The positive control was Ob.1A12 TCR bound to DRB1*15:01-MBP, with experimental structure PDB 1YMM.

What passed:
- HLA component fit the experimental 1YMM HLA scaffold closely.
- TCR chains themselves were confidently folded.
- Global ColabFold scores looked superficially strong.

What failed:
The model did not recover the known experimental TCR orientation for the positive control:
- median HLA-aligned TCR alpha RMSD: 10.227 A
- median HLA-aligned TCR beta RMSD: 18.040 A

Also, rank agreement was poor and ipTM/contact counts were not selective. In five-chain complexes, ipTM includes stable HLA alpha-beta interface confidence and is not a peptide-specific TCR binding score.

Decision:
The Ob.1A12 ternary ColabFold screen is inconclusive. It should not be reported as positive docking evidence.

Allowed statement:
    The EBV BALF5 and MBP peptide pair remains a structurally and evidence-prioritized molecular-mimicry hypothesis, but this ColabFold ternary screen was not calibrated to infer Ob.1A12 cross-recognition.

Future requirement:
A new TCR-level claim requires either:
- complete Hy.2E11 alpha/beta sequence and a calibrated receptor benchmark
- restrained/template-guided docking anchored to known structures
- experimental validation such as pMHC tetramer, binding assay, or T-cell activation assay

WHAT MAKES THIS PROJECT STRONG
1. It corrects a major biological mechanism instead of hiding it.
   The DRB5*01:01 vs DRB1*15:01 allele-pair switch is now explicitly handled.

2. It uses real experimental anchors.
   PDB 1H15 and 1BX2 anchor the positive-control pMHC comparison.

3. It is reproducible and auditable.
   The workflow keeps peptide IDs, source antigens, HLA restriction, evidence type, and file provenance.

4. It rejects overclaiming.
   Failed Ob.1A12 ternary calibration is included as a rigor point instead of being ignored.

5. It has a meaningful external validation benchmark.
   The screen recovers classic BALF5-MBP positives significantly, while showing limits for newer antigen-presentation positives.

6. It has presentation-friendly figures.
   Five publication-style figures were generated.


WHAT MAKES THIS PROJECT LIMITED
1. No wet-lab validation.
   There is no tetramer staining, binding assay, activation assay, or patient-derived TCR validation.

2. No complete Hy.2E11 TCR sequence.
   The full alpha/beta sequences were not found in checked public primary sources.

3. ColabFold ternary modeling was not calibrated.
   The model failed to recover the known Ob.1A12 orientation.

4. GSE190847 is contextual only.
   It is microarray expression data and does not directly measure EBV infection or pMHC presentation.

5. Professional-journal publication may require mentor support.
   The project is strong for science fair and possibly student journal/preprint, but immunology journals will expect stronger experimental validation.
