# External validation rank-recovery benchmark

This analysis overlays independently reported EBV/MS-positive candidates onto the predeclared pMHC shortlist.

It is a prioritization benchmark only. It does not test TCR binding, T-cell activation, affinity, or patient pathogenicity.

- classic_BALF5_MBP_pair_recovery: 10 positive pairs in a 32-pair universe; mean rank 7.1; top-10 positives 8; top-10 empirical p=0.0001
- any_external_overlay: 16 positive pairs in a 32-pair universe; mean rank 11; top-10 positives 10; top-10 empirical p=0.0003
- strict_new_literature_overlay: 5 positive pairs in a 32-pair universe; mean rank 18.2; top-10 positives 2; top-10 empirical p=0.5036
